Open source

The third-party software in each Pollis product and its licences.

Pollis is built on open-source software. Every release of every product publishes two files, produced by the release pipeline from the lockfiles the release was built with:

a CycloneDX SBOM listing each third-party Rust crate and npm package the product ships, with its version, licence, package URL and (for crates) checksum; and a summary of it, which this page shows.

The desktop and mobile apps also list every package with its full licence text: Settings → Open Source Licenses on desktop, Self → Open source licenses on mobile.

Latest release of each product

Read live from cdn.pollis.com/releases/oss/<product>/latest.json. Every earlier release's files stay at cdn.pollis.com/releases/oss/<product>/<version>/.

How it is kept current

  • Licences are checked on every change. A pull request that adds a Rust crate or an npm package under a licence not on the allow-list fails CI. The list is permissive licences, plus MPL-2.0, which applies per file, and the SIL Open Font License for bundled fonts. Strong copyleft licences such as the GPL are not on it.
  • The files are generated, not written. The same script (scripts/oss-inventory.mjs) produces each release's SBOM and the apps' licence pages, so they cannot drift apart.
  • Desktop SBOMs are signed into the release. The desktop SBOM is a subject of the release's SLSA provenance, recorded in Sigstore's public log; see Release artifacts.
What the SBOM does not list

C and C++ that a Rust crate compiles from its own source (for example WebRTC's audio processing, or the SQLCipher inside its crate) is covered by that crate's entry and licence, not listed on its own. The same goes for the native iOS and Android libraries that React Native and Expo packages bring in.

The Delivery Service SBOM covers the service's own code. The Debian base image of its container is not included.
