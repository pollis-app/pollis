# Path → flow map for `maestro-run.sh area` (#2029).
#
# One rule per line: a repo-relative bash pattern (`*` also crosses `/`), then
# the flows a change under it should run. `gate` stands for every flow tagged
# `gate`. A changed file may match several lines; the flows add up. On top of
# these lines the runner itself maps:
#   mobile/.maestro/flows/<f>.yaml       → <f>
#   mobile/.maestro/subflows/<s>.yaml    → every flow that runs <s>
#   mobile/.maestro/two-client/<d>/…,
#   pollis-tui/examples/<x>.rs           → the two-client scripts that use them
#                                          (named, not run: they need a peer)
# A line with no flows marks a path that needs none (docs). A changed file
# under mobile/ that matches no line at all runs the gate; one elsewhere in the
# repo that matches nothing runs nothing.
